# 🏥 Multi-Disease Prediction System

An AI-powered full-stack healthcare web application that predicts multiple diseases using Machine Learning models and provides healthcare-related insights in real time.

---

# 🚀 Live Demo

🔗 Frontend: https://disease-prediction-system-ecru.vercel.app/  

---

# 📌 Features

✅ Multi-Disease Prediction  
✅ Interactive React Frontend  
✅ Flask Backend APIs  
✅ Machine Learning Integration  
✅ Real-time Prediction Results  
✅ Disease Description Display  
✅ Precaution Recommendations  
✅ Confidence Score Visualization  
✅ Responsive User Interface

⚙️ Installation
Clone Repository
git clone https://github.com/ayusiparida/disease-prediction-system.git
cd disease-prediction-system
🔹 Frontend Setup
cd frontend
npm install
npm start

Runs on:

http://localhost:3000
🔹 Backend Setup
cd backend
pip install -r requirements.txt
python app.py

Runs on:

http://127.0.0.1:5000
